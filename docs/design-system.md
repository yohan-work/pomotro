# 디자인 시스템

방향: **Cozy Seoul × Miniature Realism × Subway Journey** — 따뜻하고 귀엽지만 유치하지 않게. 실제 서울의 특징(판상형 아파트와 동 번호, 옥상 녹색 방수층·물탱크, 빌라 벽돌, 상가 간판, 전신주 전선, 가을 은행나무, 한강 아치교, 스크린도어)을 미니어처 비율로.

## 토큰 (`src/app/globals.css`)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--c-primary` | #2E946B | 2호선 그린, 주요 버튼·뱃지·진행 |
| `--c-primary-ink` | #1F6E4F | 호버/텍스트 강조 |
| `--c-bg` | #F7F5F1 | Warm Ivory 배경 |
| `--c-surface` | #FFFFFF | 카드 |
| `--c-text` | #252525 | Charcoal 본문 |
| `--c-text-2` | #858585 | 보조 텍스트 |
| `--c-accent` | #F4B36B | Soft Orange — 체험 태그, 마스코트 모자 배지, 스탬프 |
| radius | 10 / 16 / 24px | s / m / l |
| shadow | `--shadow-1`, `--shadow-2` | 약한 그림자만 |

글꼴: Pretendard Variable (jsDelivr CDN, 실패 시 Apple SD Gothic Neo / Noto Sans KR). 한국어 줄바꿈 `word-break: keep-all`.

화면 검증 후 조정한 점: 기본 제안 팔레트를 그대로 확정. 시뮬레이션 화면에서는 타이머를 좌석 모켓(짙은 그린) 위 흰 글자로 올려 대비를 확보했다.

## 객실 실내 (DOM/CSS)

- 둥근 모서리 창 + 고무 개스킷(짙은 회색) + 아이보리 프레임, 창 위 실내 조명 띠
- 객실 LED 안내기(앰버 도트, 긴 문구는 마키)
- 손잡이 7개(그린 벨트 + 흰 삼각 손잡이) — 가감속 관성과 주행 흔들림을 받는 감쇠 진자
- 스테인리스 기둥, 그린 모켓 좌석(등받이·쿠션), 패널 이음선이 있는 벽
- 유리 위 마스코트 스티커(또롱), "기대지 마세요" 데칼

## 창밖 팔레트 (`src/render/palette.ts`)

낮 / 노을 / 밤. KST 기준 자동(06:30–16:30 낮, 16:30–18:48 노을, 그 외 밤), 설정에서 수동 변경 가능.
창은 서쪽을 향하므로 노을 때 해가 한강 하류 위로 지고 수면에 반사 기둥이 생긴다.

## 마스코트 "또롱"

지하철 모자를 쓴 찹쌀떡. 2호선 그린 모자, 오렌지 배지, 볼터치. 일시정지 시 졸린 눈. 승차권 스탬프에도 사용. 이모지로 대체하지 않는다.

## 금지

이모지 그래픽, 과한 글래스모피즘/그라디언트, 대시보드형 카드 나열, 무의미한 직사각형 반복, 실사 이미지 반복 스크롤, 실제 기관 로고 모사.
