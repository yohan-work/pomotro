# 개발 계획

원문 기획: `plan/phase-01-261014.md`

## 기술 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 프레임워크 | Next.js 16 + React 19 + TS | 기획 권장, Vercel 정적 배포 |
| 창밖 렌더 | Canvas 2D | 2.5D 패럴랙스로 충분, 프레임당 ~1ms. PixiJS/Three.js 불필요 |
| 실내/UI | DOM + CSS Modules | 접근성·반응형·텍스트 품질. SCSS 는 필요해지면 도입 |
| 상태 | Zustand + persist | 세션·기록·설정 |
| 애니메이션 | 자체 시간 기반 엔진 | GSAP 미사용 — 상태가 시간의 순수 함수여야 새로고침/탭 복귀가 정확 |
| 사운드 | WebAudio 합성 | 라이선스 문제 없음, 속도에 반응 |
| 데이터 | 공식 CSV → 생성된 정적 TS | 키 불필요, 공공누리 1유형, 런타임 의존 없음 |

## 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 2.5D 가 단순 이미지 슬라이드처럼 보임 | 12개 시차 레이어 + 깊이별 수면 물결 + 결정론적 다양화 + 실물 모션(가감속·진동·손잡이) |
| 긴 집중시간에 장면이 단조로움 | 터널 조명·구조물 변주, 이후 Phase 4 에서 장면 추가 |
| 실제 운행시간과 집중시간 불일치 | 재생속도가 아닌 연출 구간 길이로 맞추고, 화면에 차이 명시 |
| 공식 데이터 갱신 | `data:import` 재실행 + test:sim 정합성 검사, 실제/연출 데이터 분리 유지 |
| 저사양 성능 | 스프라이트 캐시, 가려진 레이어 생략, 자동 품질 하향 |
| 자동재생 정책 | 출발 클릭 시 오디오 시작, 새로고침 후 "소리 켜기" |

## 단계

- **Phase 0** 구조·문서 ✅
- **Phase 1** 핵심 시뮬레이션 프로토타입 ✅ (상세: `docs/phase-01.md`)
- **Step 3 (2026-10-14)** 2호선 지상 구간 확장 ✅ — 32개 역, 잠실철교·중랑천 장면, 창 방향 규칙, 지하→지상 진출, 두 번 한강을 건너는 추천 (`feat/line2-elevated`)
- **Step 4 (2026-10-14)** 공식 데이터 연동 ✅ — 서울교통공사 역간거리·소요시간(공공누리 1유형)으로 운행시간·거리 교체, 2호선 본선 순환 43개 역, 이동 거리 표시
- **Phase 2** 실제 노선 연동 — 일부 선행: 2호선 43개 역(순환), 시간 기반 추천, 역 순서 기반 다구간 이동, 역 진입/출발. 남음: 출발/도착역 직접 선택 UI, 역번호·구조 등 나머지 항목 공식 대조, 지선
- **Phase 3** 서비스 UI — 일부 선행: 출발 화면, 추천 카드, 완료 승차권(PNG 저장/공유). 남음: 반응형 세부, 구간 미리보기 이미지
- **Phase 4** 몰입감 — 일부 선행: 낮/노을/밤, 합성 효과음. 남음: 도심 고층 장면, 터널 장면 변주 확대, 장면 전환 고도화
- **Phase 5** 개인 기록 — 일부 선행: 기록 영속, 오늘 누적. 남음: 나의 서울 노선도, 방문 역 목록, 통계

## 디벨롭 로드맵 (2026-10-14 수립)

진단: 시뮬레이션 완성도에 비해 "매일 쓰는 뽀모도로 도구"로서의 기능(휴식 사이클, 백그라운드 알림, 배포)과 화면 정리가 부족했다.

### Sprint 1 — 매일 쓸 수 있는 뽀모도로 ✅
- 휴식 사이클: 도착역 승강장에 정차한 채 휴식(5분, 4회마다 15분) → 같은 역에서 이어 타기
- 백그라운드: Web Worker 틱으로 완료 판정(숨겨진 탭 타이머 스로틀링 회피), 탭 제목에 남은 시간·다음 역, 숨겨진 탭에서만 도착 알림(권한은 출발 클릭 시 요청)
- 출발역·도착역 직접 선택: 공식 거리 비율의 2호선 순환 노선도, 최소 연출 시간 안내
- PWA(manifest·아이콘·앱 셸 오프라인 캐시), OG 이미지, Vercel 배포

### Sprint 2 — 화면 다듬기 ✅
- 주행 화면 집중 모드(5초 무입력 시 HUD·커서 숨김, `H`), 손잡이 6개·짧게, LED 국문/영문 4초 교대 고정 표시
- 긴 노선은 타이머 설명에 남은 역 수, 출발 화면 데스크톱 2단(설정 | 노선도+추천) · 모바일 시간→노선→출발 순서
- 추천 노선 노선도 미리보기, 완료 화면 오늘의 진행(횟수·분·km)

### Sprint 3 — 나의 서울 노선도
- 달린 구간·방문 역을 노선도에 색칠, 일/주 통계, 연속 일수, 총 이동 거리, 승차권 다시 보기

### Sprint 4 — 풍경 확장
- 터널 교행 열차·조명 변주, 동네별 스타일(성수·구로디지털단지·신도림), 역별 승강장, 객실 실내 반응

### Sprint 5 — 품질
- 사운드 튜닝(실청취 피드백), 수동 품질 설정, 영어 UI, 단위 테스트
