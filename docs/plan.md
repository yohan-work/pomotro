# 개발 계획

원문 기획: `plan/phase-01-261014.md`

## 기술 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 프레임워크 | Next.js 16 + React 19 + TS | 기획 권장, Vercel 정적 배포 |
| 창밖 렌더 | Canvas 2D | 2.5D 패럴랙스로 충분, 프레임당 ~1ms. PixiJS/Three.js 불필요 |
| 실내/UI | DOM + CSS Modules | 접근성·반응형·텍스트 품질. SCSS 는 필요해지면 도입 |
| 상태 | Zustand + persist | 세션·기록·설정 |
| 애니메이션 | 자체 시간 기반 엔진 | GSAP 미사용 — 상태가 시간의 순수 함수여야 새로고침/탭 복귀가 정확 |
| 사운드 | WebAudio 합성 | 라이선스 문제 없음, 속도에 반응 |
| 데이터 | 공식 CSV → 생성된 정적 TS | 키 불필요, 공공누리 1유형, 런타임 의존 없음 |

## 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 2.5D 가 단순 이미지 슬라이드처럼 보임 | 12개 시차 레이어 + 깊이별 수면 물결 + 결정론적 다양화 + 실물 모션(가감속·진동·손잡이) |
| 긴 집중시간에 장면이 단조로움 | 터널 조명·구조물 변주, 이후 Phase 4 에서 장면 추가 |
| 실제 운행시간과 집중시간 불일치 | 재생속도가 아닌 연출 구간 길이로 맞추고, 화면에 차이 명시 |
| 공식 데이터 갱신 | `data:import` 재실행 + test:sim 정합성 검사, 실제/연출 데이터 분리 유지 |
| 저사양 성능 | 스프라이트 캐시, 가려진 레이어 생략, 자동 품질 하향 |
| 자동재생 정책 | 출발 클릭 시 오디오 시작, 새로고침 후 "소리 켜기" |

## 디벨롭 로드맵 (2026-10-14 수립)

진단: 시뮬레이션 완성도에 비해 "매일 쓰는 뽀모도로 도구"로서의 기능(휴식 사이클, 백그라운드 알림, 배포)과 화면 정리가 부족했다.

### Sprint 1 — 매일 쓸 수 있는 뽀모도로 ✅
- 휴식 사이클: 도착역 승강장에 정차한 채 휴식(5분, 4회마다 15분) → 같은 역에서 이어 타기
- 백그라운드: Web Worker 틱으로 완료 판정(숨겨진 탭 타이머 스로틀링 회피), 탭 제목에 남은 시간·다음 역, 숨겨진 탭에서만 도착 알림(권한은 출발 클릭 시 요청)
- 출발역·도착역 직접 선택: 공식 거리 비율의 2호선 순환 노선도, 최소 연출 시간 안내
- PWA(manifest·아이콘·앱 셸 오프라인 캐시), OG 이미지, Vercel 배포

### Sprint 2 — 화면 다듬기 ✅
- 주행 화면 집중 모드(5초 무입력 시 HUD·커서 숨김, `H`), 손잡이 6개·짧게, LED 국문/영문 4초 교대 고정 표시
- 긴 노선은 타이머 설명에 남은 역 수, 출발 화면 데스크톱 2단(설정 | 노선도+추천) · 모바일 시간→노선→출발 순서
- 추천 노선 노선도 미리보기, 완료 화면 오늘의 진행(횟수·분·km)

### Sprint 3 — 나의 서울 노선도 ✅
- 끝까지 달린 구간·방문 역을 노선도에 색칠 (중간 하차는 위치를 알 수 없어 제외)
- 누적 집중 시간·거리·완주 횟수·방문 역(/43)·연속 일수(KST), 최근 7일 막대 차트(툴팁·표 대체)
- 탑승 기록 목록과 승차권 다시 보기·저장

### Sprint 4 — 풍경 확장 ✅
- 터널 교행 열차: 우측통행 → 승객 쪽 선로, 상대속도 좌표로 결정론적 배치(약 700m 간격), 지나가는 소리, 밝기 교차 초당 3회 미만
- 동네별 시가지 스타일(연출 데이터): 성수·뚝섬 붉은 벽돌 공장, 구로디지털단지·신대방 오피스, 신도림·대림·잠실나루 고층
- 지하역 마감 5종(벽·하단·기둥 색, 원형/사각 기둥) — 역번호로 결정
- 남음: 객실 실내 반응(터널 조명, 맞은편 승객)

### Sprint 5 — 품질 (진행 중)
- ✅ 그래픽 품질 수동 설정(자동/높음/낮음), vitest 단위 테스트(통계·추천·세션·뽀모도로) + CI
- ✅ Vercel 배포: https://pomotro.vercel.app (GitHub 연결, main 푸시 시 프로덕션 자동 배포). 배포 URL 대상 브라우저 검증 26/26, 110초 완주, 60fps
- 남음: 사운드 튜닝(실청취 피드백 필요), 영어 UI

## 개선 검토 반영 (2026-10-14)

배포 화면·코드 검토로 찾은 항목을 순서대로 처리했다.

- **A 정확성·접근성**: 방치 세션은 실제 종료 시각으로 기록하고 오래된 건 회차 제외 / LED 교대 표시를 스크린리더가 반복하지 않게 / 90분 이상은 순환선 한 바퀴 직전(42개 역)까지 추천 + 나눠 타기 안내 / 알림 차단·미지원·iPhone 설치 필요 안내 / 전체화면 미지원 시 버튼 숨김
- **B 모바일**: 세로(손잡이 4개, 조작 줄 통합), 낮은 가로 화면 전용 배치, 좁은 창 모션 블러 상한
- **C 기능**: 출발 화면 설정 대화상자, 할 일 완료 체크, 기록 내보내기·가져오기·삭제, 선택 노선의 대표 장면 미리보기
- **D 다듬기**: 밤·다크 테마(토큰화), 진행 바 역 이름 툴팁, 휴식 길이·주기 설정과 자동 출발, 첫 방문·첫 주행 안내

## Sprint A — 창밖이 살아 있는 느낌 ✅ (2026-10-14)

- 서울 실시간 날씨(Open-Meteo, 30분 캐시) → 맑음/흐림/비/눈/안개. 비: 강수선(속도에 따라 기울기)·창 물방울·젖은 길·빗소리 / 눈: 눈송이·눈 덮인 지붕·지면 / 흐림·안개: 하늘·연무, 해 숨김
- 계절(KST): 봄 벚꽃, 여름 신록, 가을 은행, 겨울 나목
- 설정에서 날씨·계절 직접 선택, 개발용 `?weather=rain&season=winter`
- 안내방송(Web Speech API, 기본 꺼짐): 역 접근 시 차임 뒤 "이번 역은 ○○, ○○역입니다", 종착역 안내
