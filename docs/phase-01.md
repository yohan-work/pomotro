# Phase 1 — 핵심 시뮬레이션 프로토타입 (2026-10-14)

목표: **서울 지하철 창가에 앉아 한강 철교를 건너는 장면을 실제 브라우저에서 자연스럽게** — 정차 → 출발·가속 → 한강 횡단 → 다음 역 접근·감속 → 정차.

## 결과 요약

체험 운행(당산 → 합정, 110초)이 실제 Chrome 에서 처음부터 끝까지 실시간으로 동작한다 (`npm run verify:browser -- <url> --full`, 5초 간격 기록):

| 경과 | 상태 | 속도 | 장면 |
|---|---|---|---|
| 0–10s | BOARDING | 0 | 당산(고가) 승강장, 스크린도어 열림 → 출발 차임 → 문 닫힘 경고음 |
| 10–40s | DEPARTING | 0 → 75.6 km/h | 승강장 이탈, 방음벽 너머 당산동 시가지, 둔치 진입 |
| 40–85s | MOVING | 75.6 km/h | 당산철교 트러스 + 한강, 양화대교 아치·선유도·유람선, 북단 둔치·시가지, 갱문 옹벽으로 지하 진입, 터널 |
| 85–105s | APPROACHING | 75.6 → 0 km/h | "이번 역은 합정입니다", 터널 → 합정(지하) 승강장 진입, 부드러운 정차 |
| 105–110s | ARRIVED | 0 | 스크린도어 열림 |
| 110s | COMPLETED | – | 집중 완료 승차권 |

- 타이머는 벽시계와 일치 (매 5초 샘플에서 정확히 5초씩 감소)
- headless Chrome 1440×900: **60fps, 렌더 0.5–1.5ms/frame**, 페이지 에러 0
- 가속도 최대 1.1 m/s², 프레임 간 속도 변화 ≤ 0.02 m/s (저크 없는 출발·정차)

## 구현됨

**시뮬레이션**
- 시간의 순수 함수 엔진, 상태 8종, 저크 제한 가감속 램프
- 집중시간에 맞춘 구간 길이 조정(속도는 현실 범위 유지), 다구간(최대 17개 구간) 여정과 중간역 정차
- 일시정지/재개, 탭 비활성 시 렌더 중단·타이머 유지, 새로고침 복구, 완료 중복 기록 방지

**창밖 (Canvas 2D, 12개 시차 레이어)**
- 장면: 고가 승강장 / 고가 시가지 / 한강 둔치 / 한강 철교 / 갱문(지하 진입) / 터널 / 지하 승강장 — 서로 명확히 구별됨
- 한강: 깊이별 물결, 원경 반사, 햇빛 반짝임·노을 반사 기둥, 양화대교(아치·교각·차량·가로등), 선유도, 유람선, 새
- 시가지: 판상형 아파트(동 번호·포인트 컬러), 오피스, 상가 간판·차양·실외기, 빌라, 옥상 녹색 방수층·물탱크, 가을 은행나무, 전신주 전선, 가끔 옥상 고양이
- 역: 실제 역명·역번호·이웃 역 안내 역명판(당산 237, 합정 238), 스크린도어 개폐, 기다리는 승객
- 터널: 조명 리듬, 케이블 트레이, 비상구 유도등, 거리표, 신호기, 피난 연결통로, 벽에 맺힌 열차 실내 불빛
- 낮 / 노을 / 밤 팔레트(KST 자동 + 수동)
- 주행 진동, 가감속 관성 기울기, 전차선 지지대 모션 블러, 터널에서 강해지는 유리 실내 반사

**객실 실내 (DOM)**
- 둥근 창·개스킷·프레임, LED 안내기(다음 역/이번 역/출입문 닫습니다/종착역), 가감속에 반응하는 손잡이 진자, 기둥, 그린 모켓 좌석, 마스코트 스티커
- HUD: 노선·구간, 현재 시각, 할 일, 남은 시간, 역 진행 표시(다음 역), 일시정지·소리·화면설정·전체화면, 내리기(부분 기록)

**사운드 (WebAudio 합성, 채널별 볼륨/음소거)** — 주행음, 인버터음, 레일 이음매(철교에서 다른 음색), 터널 울림, 출발/도착 차임, 출입문 경고음·공압음, 객실 앰비언트

**부가** — 출발 화면(시간 선택·할 일·추천 노선 3개·차이 안내·실시간 한강 배경), 완료 승차권(캔버스 → PNG 저장/공유), 오늘 누적 집중시간, 모션 감소 설정, 모바일 세로 레이아웃

## 미구현 / 한계 (정직한 목록)

- **데이터 미검증**: 역 정보·지상/지하 구조는 공개 노선도 기반, 역간 운행시간은 추정치. 공식 API 연동 안 함 (`docs/architecture.md` §데이터)
- 이동 거리: 실제 거리 데이터가 없어 완료 화면·승차권에 표시하지 않음
- 출발역/도착역 직접 선택 UI 없음 (추천 3개 + 체험 운행만)
- ~~합정 이후 구간은 모두 지하라 긴 집중 세션은 대부분 터널 장면~~ → Step 3 에서 고가 구간·잠실철교 추가로 해소 (도심 고층 장면은 여전히 Phase 4)
- 사운드는 브라우저에서 실행·무에러만 자동 검증했고, 음색 품질은 사람이 들어보고 조정해야 함
- 실제 GPU 저사양 기기 성능은 미측정 (자동 품질 하향 로직은 있음)
- 나의 서울 노선도, 기록 목록 화면 없음 (기록 데이터는 저장됨)
- 구간 미리보기 이미지 없음 (출발 화면 배경은 실시간 렌더)
